# Brand and visual system

Product: Repo Necromancer. Event: Kiroween 2026.
Tagline (exact): "Build something wicked and git commit to the darkness."
Supporting line (exact): "Diagnose. Reanimate. Verify."
Direction: Haunted Cyberpunk, a gothic software-forensics engineering console. Credible and
readable for engineers. No gore, blood, cartoon Halloween art, horror fonts, WebGL or heavy 3D.

## Colour meaning
- Emerald means verified or healthy only when backed by real evidence.
- Violet means AI or agent activity, never success.
- Amber means approval required, pending attention or a warning.
- Crimson means failure, blocked operation or critical finding.
- Ice blue means neutral information.
- Never use colour alone for status; pair it with text and an icon. Target WCAG AA.

## Typography
Space Grotesk (headings), Inter (body), JetBrains Mono (terminal, code, paths, diffs),
IBM Plex Mono (scores, counts, durations, identifiers). Use sensible system fallbacks.
